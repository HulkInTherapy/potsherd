# Terminal audit

`potsherd audit` opens the retrospective. `--legacy` opens the retention audit; `--sweep` and `--verify` keep their prior routes. This checkout is a candidate; a source test is not proof of installed or live-provider qualification.

The first wall shows all-time recorded API-equivalent value at a named Models.dev snapshot, token/pricing coverage, a favourite model combining equal token and conversation measures, real project names, recent work and short source quotes. Known priced portions are distinct from unknown usage and pricing. The value is a revaluation at current catalog rates, not an invoice or subscription bill. Native per-response models/providers and token buckets preserve cache/reasoning inclusion and cumulative/duplicate semantics. Unknown endpoint, custom model and unmatched revisions remain unknown. pi/OpenCode user projections do not establish human authorship.

Left/right or Tab switches Models, Projects, Work, Hall of Fame, Language and Timeline. Up/down selects, Enter opens details or exact source evidence, Esc returns, S freezes the current visible view, q exits. F exposes the available periods and their estimates before an expanded analysis. The command's total token reservation includes all calls and retries across period changes. Real project names and selected source lines remain visible in a frozen view; JSON and explicit safe SVG exports use the separate public aggregate serializer. No automatic posting occurs.

An opening notice names OpenCode Zen and TypeSafe/Jev as recipients of selected redacted conversation text. There is no additional startup Enter prompt or consumer key requirement. The official OpenCode loader keeps zero-input-cost models available without authentication and uses the public literal credential; this is not an embedded account secret. A synthetic request to the exact free Jev model returned HTTP200 with zero cost and validated typed answers. Client-side concurrency, request/deadline/token reservations, cancellation and strict zero-cost responses bound the direct route. No paid model, billing enrollment, automatic reload or key embedded in npm is a fallback. Capacity loss leaves local facts and completed cached work intact; another invocation may resume after legitimate capacity becomes available. Private developer pilots require exact payload review and authorization independently of this consumer design.

The local pipeline inventories native sources, sizes complete contextual segments, selects All/45/30/7/3 days within the same allowance, or a visibly partial selection of the newest whole episodes when calendar windows exceed it, and asks typed Choice/Score/Noul questions. Complete conversations fit one segment; long histories use complete turns with preceding context and explicit gaps. Standalone oversized turns are skipped with coverage, never silently truncated to a successful prefix. Work attempted, assistant-reported success and success supported by recorded results are distinct. User tone/quotes require direct-user evidence. Literal profanity uses a versioned English lexicon and conservative direct/quoted/code/unknown buckets; it does not diagnose personality or claim multilingual coverage.

Source stores remain read-only. Existing frozen SQLite, live-WAL holds, per-record project/ignore, forget, lineage, redaction and currentness fences apply before transfer, cache use and source reads. Changed source or policy clears launch findings. Derived usage, typed answers and verified date intervals live separately under `audit-derived`, with0700directory/0600files and atomic writes; full conversation bodies and selected quotes are not stored in that cache. Cache identities bind content, currentness, source/privacy/forget, question/model/segmentation versions. Date skips require actual verified event intervals and unchanged identity; mtime is never an event-date substitute. Public catalog refresh is bounded and saves a validated snapshot for future reports; it does not silently reprice an existing report or rerun Jev.

Remaining candidate gates: fresh installed direct free-route flow, representative authorized semantic evaluation, independent installed native/terminal journeys and timing, package/privacy/vendor parity, complete release checks and npm provenance.
