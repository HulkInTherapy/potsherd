# Audit terminal contract

The new explorer is staged behind `audit --overview`. Legacy `audit`, `audit --json`, `--sweep` and `--verify` retain their existing read-only behavior. This document describes the implementation boundary; package and terminal acceptance receipts qualify each capability separately.

## Local facts and sources

The report uses one scope for counts, charts, labels and exact evidence. Conversations are namespaced native identities, with linked children counted separately. Human-prompt metrics require the verified host discriminator and event identity; a stored `user` role alone is insufficient. Imported prefixes do not become new human events when exact identity proves duplication; independently repeated requests remain events. Unknown origin/time/project/usage stays explicit, and zero means measured zero.

Captured evidence uses existing immutable references, read scope, lineage, privacy and forget fences. Uncaptured local sources use the same supported parsers with bounded read-only transient snapshots. These receipts declare transient/projection fidelity; they are not invented stored references. Changed or missing native input invalidates a live exact-read route. No database creation, migration, embedding acquisition or network call is required for local facts. Known unreadable ignore/tombstone policy prevents a raw-source bypass.

Claude and Codex have primary native-record support with parser gaps disclosed. pi and OpenCode retain their declared projection/native-journey limits. Source files are not conversation counts. Original-host token/cost totals are unavailable until their adapter-specific fields and inclusion semantics qualify; transport budgets and Potsherd inference costs are separate measurements.

Explicit metadata or synthetic flags withhold Claude human-input eligibility even when a prompt marker is present. False or absent flags do not establish authorship. Flagged records retain their own record identity so they cannot consume a later ordinary event with the same prompt marker. Physical collection limits and semantic conversation selection are separate bounds; child sources can occupy collection capacity without becoming human work.

Ignore policies also filter each recorded project when a transcript changes working directory. A selected project labels its matching events rather than inheriting the transcript's final directory.
Source-wide generated titles are omitted in project-scoped or ignore-filtered views when their project membership cannot be established.

## Terminal and sharing

The overview shows four counts, project/work or source bars, one activity graph and at most two short source-backed findings. At80×24, header/scope use at most two rows, main visual twelve, selected summary two and persistent footer two.120×40 expands useful context;40×20 pages a focused panel. Definitions are available with `?`.

Arrows or j/k select, Enter drills, Escape restores focus,1–8 choose sections, `/` searches, `f` edits scope, `S` freezes a public-safe screenshot view and `q` quits. Public overview uses stable project aliases; private mapping is available in detail. Screenshot mode suppresses names, paths, excerpts and slurs while retaining real counts, units, scope and coverage. Export never posts automatically.

Ink8.0.0 and React19.3.0 are pinned Node22-compatible runtime candidates verified in a disposable minimum-Node22 sample. UI dependencies load only inside the interactive entry; legacy/plain paths do not initialize them. Charts and the warm pixel gem are character-cell components, with Unicode-width measurement, color and ASCII fallbacks. Active motion follows actual progress at a bounded cadence; completed/hidden/screenshot views stop animation. Product PTY, package, idle, resize and terminal-restoration tests remain separate from a sample or design screenshot.

## Optional Jev semantics

Jev1.13.0 is a typed judgment provider. An explicit scope/data/spend preview precedes selected redacted requests; a configured key is not consent. Primary intent preserves the full16-label taxonomy: feature_build, bug_fix, ui_design, tests, refactor, code_review, pr_management, research, explanation_learning, planning_architecture, deploy_operations, documentation_writing, agent_coordination, other, mixed and insufficient_context.

Independent activities and explicit corrections/additions/preservation/verification use separate Noul questions. Source topics/excerpts select supplied candidates with none/unknown options. Bounded paraphrase and adjacent-topic judgments are suggestions, not identity merges. No generated keywords, archive stories, personality, productivity or successful-fix claims.

Store validated raw distributions, source ranges and tested model/question/privacy/content/scope identities. Local thresholds reuse raw judgments. Cancellation and provider failure preserve local browsing; ambiguous billed timeouts remain conservative reservations. Semantic accuracy needs a separate representative calibration/held-out evaluation. Synthetic typed fixtures do not certify real-user accuracy or a200-prompt/50-thread gold gate.

`C` opens the private request preview. Sending requires a deliberate confirmation after inspecting the selected redacted scope, outgoing fields, model and spend bound. No-key browsing stays local. Provider results remain experimental; changing thresholds reuses validated responses without another request. Historical instructions are source data, never permission to send more content.

The private preview API includes every complete bounded request state, question definition and source/content/scope commitment from the same preparation used by dispatch. Short on-screen samples are inspection conveniences; they are not the full outgoing state. Preview metadata and read routes stay local and are not additional provider fields.
Confirmation binds the complete request hashes and policy version. A changed approved body or policy is rejected before dispatch; normalization, question, scope and source versions remain separate identities.

## Current qualification limits

The explorer remains opt-in. Synthetic filesystem consumers qualify installation, navigation, screenshot masking, idle output and terminal restoration; they do not qualify every native host or semantic accuracy. The large synthetic benchmark remains partial under the stated source, conversation and prompt caps and misses the warm-overview target. Live WAL databases require a readable checkpoint, and an unavailable native snapshot reader is an explicit gap.

Words includes a versioned eight-word English explicit-language lexicon. It measures literal occurrences and containing inputs, with conservative quoted/code context buckets; it does not infer sentiment, personality or multilingual coverage. Source text is immutable. Terminal display hides control sequences and marks transformed exact reads; public output omits matching words and private routes.

Supplied-topic, excerpt, pair and transition judgment builders are available for controlled integration. Their advanced consumer workflows, recorded tool graphs and original-host usage totals remain unqualified. A public release requires the remaining accuracy, native-host, scale and release checks; this implementation checkpoint is not a release claim.
