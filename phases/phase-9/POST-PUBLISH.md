## the one thing that needed a person

`npm publish` returned **`E403 — Two-factor authentication or granular access token with bypass 2fa
enabled is required to publish packages`**, with `npm whoami` succeeding and the account's own
`two-factor auth: disabled`. So this was npm's publish policy rather than account enforcement, and
there was no OTP for meghavi to read — the first guess (that 2FA was enforced on the account) was
wrong and was corrected against `npm profile get`.

meghavi supplied a granular access token. It was used through a `--userconfig` file in a `mktemp -d`
outside the repository, deleted in the same command. **No credential was written into the working
tree, and none was created by the agent** — `phases/phase-9-go-live.md` forbids that explicitly.

**The token should be revoked now that the publish is done.**

## rollback, if it is ever needed

```
npm deprecate potsherd@1.1.0 "withdrawn — use <version>; see <url>"   # unpublish is 72h-limited
gh release delete v1.1.0 --yes
```

Do not force-push `main` to undo a publish: the registry does not care what the repository says, and
a rewritten history makes the published tarball unauditable.
