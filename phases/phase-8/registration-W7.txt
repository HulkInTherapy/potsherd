WHAT THIS TASK FOUND
--------------------

The brief named two locations. A repository-wide inventory, cross-checked by
hand against the READ-ONLY reference archive and the four live harness
directories, found **25 distinct real session ids in 39 tracked files** — not
two files, and not ten ids.

  method, so the number can be re-derived rather than believed:
    - every id-shaped token (a uuid, or an 8-hex run standing alone) in every
      tracked text file AND in every tracked file NAME:   175 distinct id8s
    - every session/thread uuid under ~/.potsherd/archive-manual-2026-08-21,
      ~/.claude, ~/.codex, ~/.cursor, ~/.pi:               3,013 distinct id8s
    - the intersection, matching full uuids in full and 8-hex tokens on the
      id8 (which IS the identity potsherd resolves by):    25 ids, 39 files
  collision risk on the 8-hex half: 3,013 x 175 / 2^32 = 1.2e-4 expected false
  matches, and every match was read in context before it was acted on.

The single worst one is not in `phases/**` at all. **One real session id from a
paying developer's machine is the canonical eight-hex example for every verb**
— `tag`, `pin`, `unpin`, `link`, `ls --linked-to`, `graft`, `card`, and the
"needs a session id" error message — across `packages/cli`, `packages/core`,
`packages/mcp`, seven test files, the vendored plugin bundles and one plugin
skill. A second real id is the other end of the `link` example. Both are
printed by `--help` on every user's terminal.

It survived T5.9's family-(2) sweep, which replaced ONE such id with the demo
corpus's `9c4d2f18` and left this one, and it survived every run of
`check-privacy.py` since, because that rule was an enumerated blocklist.
