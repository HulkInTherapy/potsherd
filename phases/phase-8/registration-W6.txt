================================================================================
2b. packages/cli/src/index.ts — `--k` must stop defaulting in commander
================================================================================

WHY (this one is load-bearing, not tidying). `--k` is registered with
`.default(ASK_K)`, so `opts['k']` is `6` on every run whether or not the user
typed `--k`. `runAsk` cannot then tell "unset" from "6", and `--fast` silently
read six sessions. Measured before the fix: `potsherd ask "…" --fast` printed
`6 of 53 sessions read`. Dropping the commander default lets `runAsk` choose
between {@link ASK_K} and {@link ASK_FAST_K}, and an explicit `--k` still wins
over both. The default moves into the description so `--help` still states it.

ANCHOR — line 305 at 67dfaa5, in full:

      .addOption(new Option('--k <n>', 'sessions to read').argParser(Number).default(ASK_K))

REPLACE that whole line with:

      .addOption(new Option('--k <n>', `sessions to read (default ${ASK_K}; ${ASK_FAST_K} with --fast)`).argParser(Number))
