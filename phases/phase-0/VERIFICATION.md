| # | severity | defect | outcome |
|---|---|---|---|
| D-CI | high | the sweep test read a fixture mtime; git does not preserve mtimes, so it passed locally and failed on every fresh clone | **fixed** — the test stamps mtimes itself |
| D1 | high (honesty) | the README card was headed `~/.claude` but its numbers came from the frozen copy | **fixed** — all screens regenerated from a demo corpus, honestly labelled |
| D2 | high (honesty) | `346 MB` in README and HANDOFF was produced by no command | **fixed** — `329 MB`, from `audit --json`.`bytes` through `format.bytes()` |

| D4 | medium | guard hook median ~1.0 s against a < 1 s target (1.20/0.89/1.00/0.96/1.05/1.07/0.57/0.40) | **fixed** — 0.11 s median; scan reads no file content, ghost rebuild skipped on an unchanged `sync_state` fingerprint |
| D5 | medium (privacy) | `docs/screens/` published real project and client names and `/Users/zebra` paths | **fixed** — demo corpus; a check in `make-screens.sh` fails on any forbidden string |

| D7 | medium | the rescue receipt's sweep row printed a truncated absolute path when the settings edit was refused | **fixed** — `settings.json left untouched` |

| D11 | low | pluralisation (`all 1 are recoverable`); at width 60 the closing fix line truncated mid-word | **fixed** — `format.plural`; `Card.fix()` drops the explanation before the command |
