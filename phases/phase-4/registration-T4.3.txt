3.  packages/cli/src/commands/doctor.ts  —  THE PRIVACY LINE
================================================================================
NOT RESERVED, and T4.3 has already made this edit on `task/T4.3-graft`.
It is recorded here so the integrator can see it in one place, and so it
survives a cherry-pick of the three product files.

`graft` writes a path that is NOT under ~/.potsherd. `03` §11 requires
`doctor --privacy` to list every path written, and this receipt has
under-reported once already (it said "no network" after the product had
started calling a model). The change, in `runDoctor`:

  BEFORE
    const written = [root, paths.archiveDir(root), dbFile, paths.modelsDir(root)];

  AFTER
    const written = [
      root,
      paths.archiveDir(root),
      dbFile,
      paths.modelsDir(root),
      // `graft` is the one verb that writes outside ~/.potsherd: the brief
      // lands in the project you run it in, which is the entire point of the
      // verb. `--privacy` lists every path written, so it lists this one.
      path.join(process.cwd(), '.potsherd', 'graft-<id8>.md'),
    ];

plus, in the `--privacy` block, immediately after the `for (const p of written)`
loop, the one line of prose that says the path is conditional:

    card.raw(`      ${t.dim('the graft path only when you run graft, in the directory you run it in')}`);

`packages/core/src/graft.ts` exports `GRAFT_WRITE_PATH_NOTE` holding
"./.potsherd/graft-<id8>.md  (the current directory, when you run graft)"
and `graftDir(cwd)` / `graftPath(id8, cwd)` if doctor would rather compute it.
`doctor.ts` already imports `path` and `process`.
